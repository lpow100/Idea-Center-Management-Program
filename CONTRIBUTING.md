# CONTRIBUTING
## Commit Standards
 - Main Branch: Only push or merge functional, tested code.
 - Style: Adhere strictly to the project's style guidelines defined in this document.

## Documentation
Write documentation that is accessible to all skill levels.
For backend changes, explicitly document all API endpoints, parameters, and responses.

## Collaboration
Maintain clear communication between frontend and backend teams. Avoid overly complex jargon; ensure explanations are understandable for developers of varying experience levels.

## Code Philosophy
Prioritize clean, maintainable code over micro-optimizations. Trust the compiler to handle performance.
Unreadable or obfuscated code is subject to reversal. Write for your peers, not just for the machine.

## Policy on AI
AI shouldn't write any code, AI should be a tool to solve problems not to generate code. Any AI generated code will be removed but AI is okay for help with ideas.
