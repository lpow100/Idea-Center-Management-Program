# CONTRIBUTING
## Commit Standards
 - Main Branch: Only push or merge functional, tested code.
 - Style: Adhere strictly to the project's style guidelines defined in this document.

## Documentation
Clarity: Write documentation that is accessible to all skill levels.
Endpoints: For backend changes, explicitly document all API endpoints, parameters, and responses.

## Collaboration
Inclusivity: Maintain clear communication between frontend and backend teams. Avoid overly complex jargon; ensure explanations are understandable for developers of varying experience levels.

## Code Philosophy
Readability > Optimization: Prioritize clean, maintainable code over micro-optimizations. Trust the compiler to handle performance.
Enforcement: Unreadable or obfuscated code is subject to reversal. Write for your peers, not just for the machine.
