## Pushing
When you are pushing or commiting you must be pushing or commiting a working version with updated insructions (if neccacery)

## Insructions
All backend developers must create a USAGE.md file for the frontend developers to use that lists all of the functions and interactions needed between the frontend and backend.

## Co-Developing
You are developing with other people. Not everybody is as advaced as everyone else. Please take not of this when explaining or interacting between frontend and backend.

## Readability
All code should be readable and understandable by everybody (with explanation from the developer). There should be no code that is unnecacarily complex. (If you have ideas for a refracotring, please suggest them to the developer resopnsible for that section before making major changes.)
